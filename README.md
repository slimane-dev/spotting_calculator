# WellSpot 0.5 for Windows x64

This delivery branch contains the portable Windows package, published with the repository owner's approval.

Download `WellSpot-0.5-Windows-x64.zip`, right-click it and choose **Extract All**, then double-click **WellSpot.exe** in the extracted folder. Keep its bundled files together. No separate runtime or installer is required.

WellSpot includes cement-job and kill/pill calculations, editable pump output and stroke results, named saved jobs, and bundled offline schematic OCR.

Build validation: 313 checks passed on Linux, including a run with internet sockets denied. Windows execution and the Windows user interface have not yet been tested. This build is unsigned; Windows may show an unknown-publisher warning.
